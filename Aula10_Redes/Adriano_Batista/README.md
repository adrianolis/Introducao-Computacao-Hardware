# Aula 10 – Redes de Computadores: Histórico, Elementos e Classificação
## Nome do aluno: Adriano Lisarb Guzmán Moura Batista
## Objetivo
Compreender a evolução das redes de computadores, identificar seus 
elementos básicos e classificar diferentes tipos de redes.

## Descrição
Este trabalho apresenta visualmente a evolução histórica das redes de 
computadores, os 4 elementos fundamentais da comunicação em rede e a 
classificação das redes por abrangência geográfica, com exemplos reais.
