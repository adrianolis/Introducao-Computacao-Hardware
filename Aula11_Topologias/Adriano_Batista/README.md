# Aula 11 – Redes de Computadores: Topologias, Dispositivos e Meios
## Nome: Adriano Lisarb Guzmán Moura Batista
## Objetivo
Entender a organização física e lógica das redes, identificar os 
principais dispositivos e reconhecer os diferentes meios de transmissão.

## Descrição
Este trabalho apresenta visualmente as principais topologias de rede, 
um quadro comparativo entre os dispositivos Hub, Switch e Roteador, 
um esquema dos meios de transmissão guiados e não guiados, e uma 
reflexão individual sobre a topologia ideal para uma rede residencial.

## Arquivos entregues
- `topologia.png` – Diagramas das 4 topologias de rede
- `dispositivos.png` – Quadro comparativo entre Hub, Switch e Roteador
- `meios_transmissao.png` – Esquema dos meios de transmissão
- `reflexao.pdf` – Reflexão individual sobre topologia residencial
